# Checklist SEO & Performance — avant lancement

## Apps

- [ ] Compter le nombre d'apps installées — viser le minimum vital
- [ ] Vérifier chaque app pour son impact JS (via Shopify > Thème > Rapport
      de performance du thème)
- [ ] Éviter les apps qui injectent des popups/scripts sur toutes les pages

## Images

- [ ] Toutes les images en WebP ou format optimisé par Shopify (CDN natif)
- [ ] Alt text renseigné sur chaque image produit
- [ ] Pas d'images surdimensionnées (redimensionner avant upload)

## Métadonnées

- [ ] Meta title + meta description unique par page/produit/collection
- [ ] Titres de pages cohérents avec les mots-clés ciblés
- [ ] Balises H1 uniques par page (une seule par page)

## Technique

- [ ] Sitemap.xml généré automatiquement (Shopify le fait) et soumis à
      Google Search Console
- [ ] Robots.txt vérifié (pas de blocage accidentel de pages importantes)
- [ ] Redirections 301 configurées si migration depuis un ancien site
- [ ] Données structurées produits (schema.org) actives — vérifier avec le
      Rich Results Test de Google

## Core Web Vitals

- [ ] Score testé via PageSpeed Insights (mobile + desktop)
- [ ] LCP < 2.5s, CLS < 0.1, INP < 200ms
- [ ] Thème testé sans apps tierces d'abord pour établir une baseline

## Analytics

- [ ] GA4 installé et events e-commerce configurés
- [ ] Meta Pixel installé (si publicité Meta prévue)
- [ ] Consentement cookies configuré (RGPD)
